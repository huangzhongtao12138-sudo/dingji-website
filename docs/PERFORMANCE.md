# 2026-10-10 性能优化记录

## 证据与范围

- 原线上石鼎香页直接引用 8 张 JPG，无图库延迟加载；8 张合计 164,302,420 bytes，最大照片 10000×10000 像素。
- 原线上封面 HEAD 返回 `Content-Length: 22331706`、`server: Vercel`、`x-vercel-cache: HIT`、`x-vercel-id: sin1::...`。即使缓存命中，仍需传输原始大图。
- 新石鼎香全套 1920 档 WebP 合计 1,976,362 bytes，约减少 98.8%。封面 1920 档约 220 KB；浏览器根据屏幕、像素密度与封面裁切选择尺寸，不能将最小文件大小视为所有手机的实际流量。
- 香园原始 JPG 合计 96,808,721 bytes，新 1920 档合计 992,624 bytes。
- 保留所有原始素材，仅改网页引用；四个案例及案例列表使用响应式 WebP，图库延迟加载、异步解码、预留尺寸，点击放大才请求最大网页尺寸。
- 用户明确选择原生滚动，全站去除 Lenis 引用。首页视频按可见性加载和暂停，使用单视频循环；粒子动画限制绘制频率并离屏停止；首页与关于页导航弹簧停止空闲刷新。首页去除 Google Fonts 外链样式请求。
- 顺手修复回归测试发现的荣誉页 1181px 双栏最小宽度溢出，改为可收缩网格。

## 验证

- 本地 Chrome/Playwright：14 个正式页面 × 390、640、641、800、1024、1180、1181、1280、1614px，共 126 个组合，无横向溢出或 JavaScript 运行错误。
- 额外视觉检查：390px 与 1440px 首页、案例页、石鼎香首屏，以及石鼎香图库；截图等待异步解码及入场动画完成后核对。
- 点击图库请求 1920 档图片，Escape 正常关闭；首页首屏视频无 src、只有一个播放器；离屏后粒子帧循环与导航帧循环均停止；减少动态效果时不自动加载视频且粒子不持续绘制。
- 内部链接、src/srcset、放大图地址、JSON-LD、sitemap、Vercel JSON 与 git diff --check 通过。
- 本地浏览器验证屏蔽外部资源；不将该检查声称为跨境视频播放验证或大陆线路测速。

## 仍需区分的网络问题

托管仍为 Vercel，首页视频仍来自 CloudFront，关于页 3D 查看器仍来自 unpkg。前端改动显著减少案例传输量和空闲计算，但不能保证所有大陆运营商到海外节点的延迟。单次 sin1 响应不是全国网络测速，后续是否迁移托管应基于用户实际网络复测。


## 2026-10-15：第二轮优化

### 具体改动

- 首屏无需等外部共享 CSS：业务案例与首页减少 2 个阻塞样式请求，4 个案例详情减少 1 个。通过 `scripts/inline-critical-styles.py` 从共享文件更新嵌入内容，`--check` 检查同步。
- 业务案例移除默认隐藏/模糊的入场条件和整页指针渐变重绘，关闭 JavaScript 时标题与正文仍可读。
- 列表使用 480/960px 方形 AVIF 缩略图及 WebP 回退；石鼎香列表桌面 480px AVIF 约 24 KB，高像素密度手机可选择 960px 版本，不能把最小体积宣称为所有设备的流量。
- 详情首屏 AVIF 保持裁切与清晰度选择；石鼎香 1920px 封面从 218,048 字节 WebP 降到 156,109 字节 AVIF，约减少 28.4%，WebP 仍作格式回退。
- 公开 HTML 300 秒缓存；悬停/键盘聚焦时最多预取 4 个同源公开页面，省流量/2G 跳过，单次超时 5 秒。资产与脚本继续使用版本化地址。

### 已记录的诊断与验证边界

- 前期在线两次样本中业务案例 HTML 总耗时约 1.63/1.80 秒，首字节约 1.63/1.77 秒，传输体积仅 12,341 字节；说明该测试线路的主要等待在连接/首字节。该环境不是全国运营商测速，也不能替代用户实际线路。
- 受控测试将每个外部 CSS 响应延迟 800ms，旧版标题达到可见状态约 1405ms，新版约 53ms且没有外部 CSS 请求；这是本地受控结果，不是正式网站加载时间承诺。
- 2026-10-15 发布前复查覆盖 14 页 × 9 宽度；同时检查首屏无额外样式请求、无 JavaScript 仍显示文字、实际选用 AVIF、图库放大/Escape、从全新浏览器上下文预取后导航命中缓存。
- 共享 CSS、图片地址、内部链接、JSON-LD、sitemap、Vercel JSON 与 diff 格式均检查；具体发布结果以线上响应核对为准。

网络限制参考：[Vercel 官方大陆访问说明](https://vercel.com/kb/guide/accessing-vercel-hosted-sites-from-mainland-china)。Vercel 无大陆节点，后续需要稳定国内访问时，托管线路仍是独立事项。
