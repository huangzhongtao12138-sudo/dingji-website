## 十、全站展示型标题维护规则

- 关键标题必须在 HTML 中按语义分段，不能只靠 `text-wrap: balance` 或容器宽度碰巧换行。
- 桌面和平板优先保持已确认短语整行；手机端需要换行时，在 640px 明确切换为固定语义行。
- 主标题与副标题使用独立行，副标题可按比例缩小以保证完整短语不拆分；按钮和导航短文案保持 `white-space: nowrap`。
- 字号使用有明确最小值和最大值的 `clamp()`，页面启用 `text-size-adjust: 100%`，避免浏览器自动放大造成字号突变。
- 关于页首屏的文字与数据栏以可控页面边距定位，不在常见宽屏下因内容最大宽度居中而大幅改变左侧位置。
- 排版回归测试至少覆盖 390、640/641、800、1024、1180/1181、1280 和 1614px，并检查全页横向溢出。
